# 事件时序约束校验器（Temporal Constraint Checker）

用于**采访证词核对**与**事故复盘时间线分析**的 Web 应用。用户录入两类信息：

1. **相对时序约束**（自然语言）：事件 A 比事件 B **早 / 晚** `x` 到 `y` 分钟；
2. **绝对时间观测**（可多条）：某事件发生在 `[最早时刻, 最晚时刻]` 区间内；
   两端填同一时刻即为**精确时刻（零宽区间）**。

系统把所有观测与相对约束接入**同一张差分约束图**（Difference Constraint System，
观测统一挂到虚拟“绝对时间零点”节点上），实时完成：

1. **可满足性实时判定** —— 观测之间、观测与相对约束之间一旦矛盾（图中出现负环）立即报警；
   冲突检测在统一图上一次完成，**不按锚点逐条独立判断**；
2. **矛盾链高亮复核** —— 突出显示一条具体的矛盾链：图上红色节点/边、约束与观测列表红色行，
   并逐条列出链上的差分不等式（观测边自动换算为绝对时刻），求和得到 `0 ≤ 负数` 的代数证据，
   分别映射回原始证词与原始观测，**链上涉及哪些观测、哪些原约束一目了然**；
3. **最小修复建议** —— 检测到矛盾时，以每次发现的负环为分支依据搜索
   **停用约束/观测数量最少**的可满足方案（观测与约束同为修复候选）；并列最优方案最多展示 5 个
   并按录入顺序稳定排序，每个方案列出需停用的约束/观测与修复后的事件时间窗，支持**不写入
   localStorage 的一键预览**与**确认应用**（确认后批量停用）。搜索累计超过 2000 个状态即停止，
   并明确标记结果可能不完备；
4. **绝对时间窗计算** —— 可满足时给出每个事件的**最早 / 最晚绝对时刻**；
   正/反向都不被任何观测连通的事件标记为「无法定时」；
5. **边界依据追溯** —— 点击时间窗表中任一事件的**最早 / 最晚时间**，展示从绝对时间零点推导该
   边界的**紧约束链**：按推导顺序逐步列出采用的原始观测 / 相对约束、上/下界侧不等式与累计绝对
   时刻，并在**差分图、约束列表与观测列表中同步紫色高亮**；最早边界由反向图路径正确还原为原始
   边（步骤标注「反向」），观测边标注「观测」。单边无界或无法定时的单元格不可点击，悬停可见
   原因。任何编辑或进入/退出修复预览都会自动清除旧追溯，预览中的追溯按有效条目重新计算；
6. **无法定时标记** —— 未被任何观测（经相对约束）连通的事件标记为「无法定时」；
7. **分层最小偏差排程** —— 系统可满足且至少有一条观测时，可为一个或多个事件填写
   **期望绝对时刻**，并为每个期望选择**高 / 中 / 低**优先级（默认「中」）。系统对**整体差分系统**
   （相对约束 + 全部观测）按 **高 → 中 → 低 字典序**最小化各层最大偏差：先求高层的最小非负整数
   容差 `D_高`，把 `±D_高` 的钉住约束固定进差分系统后再求下一层（**不是**加权和，也不是分层
   各自排程后拼接，同样**不是**把各事件独立夹到现有时间窗），最终输出一份**同时满足全部启用约束、
   全部观测与各层容差的确定性可行排程**：每个已定时事件的实际绝对时刻、所属层级与相对期望的
   偏差，以及每层的最优 `D` 与达到 ±D 的事件；仍未被观测连通的事件明确标为「未定时」
   （其上的期望与层级不参与搜索）。编辑约束、观测、期望或层级后实时重算，
   矛盾状态下不显示任何旧排程结果；
8. **示例数据 + 本地持久化 + 旧存档迁移** —— 内置「事故复盘（可满足）」与「采访证词冲突」两套
   示例，全部编辑内容（含观测、期望时刻与优先级层级）自动保存在浏览器 `localStorage`
   （修复预览除外）；**旧版本的单锚点存档打开时自动迁移为一条精确观测**，旧版缺失优先级字段的
   存档按「中」优先级参与排程。

技术栈：React 18 + TypeScript + Vite，纯前端、无后端依赖。

## 一条命令启动

需要已安装 Docker（含 Compose 插件）。在项目根目录执行：

```bash
docker compose up --build -d
```

启动后访问（端口与访问方式保持不变）：

> **http://localhost:8080**

镜像构建时会自动完成依赖安装（`npm ci`）与生产构建（`tsc + vite build`），
容器启动即由 nginx 直接托管静态产物，**无需任何额外初始化步骤**。

常用命令：

```bash
docker compose logs -f        # 查看日志
docker compose down           # 停止并移除容器
docker compose up --build -d  # 代码更新后重新构建启动
```

### 修改访问端口

编辑 `docker-compose.yml` 的端口映射，例如改用 9090：

```yaml
ports:
  - "9090:80"
```

然后重新 `docker compose up -d`。

### 算法自测

```bash
npm test
```

覆盖（节选）：

- **边转换**：相对约束 → 两条差分边；精确观测（零宽区间）→ 对时间零点的等权夹逼边；
  区间观测上/下界边；非法区间（左 > 右）不产生边；禁用条目不参与；
- **时间窗**：可满足示例的全部绝对时刻数值；两条精确观测 + 相对约束共同夹出中间事件窗口；
  无观测时全部「无法定时」；独立连通分量无法定时；精确间隔退化为点；
- **矛盾链**：纯相对约束负环（不涉观测）、同一事件两条互斥精确观测（链同时含两条观测并经过
  时间零点）、观测落在约束窗口外（链**同时含观测与原约束**）、区间观测与约束不相交；
  环边/节点严格对齐、权重求和；
- **最小修复**：纯约束矛盾的最少停用数与并列方案；观测/约束冲突时停用观测或约束均为候选；
  互斥观测的两个并列方案；双负环组合、状态上限截断、停用条目不参与搜索等；
- **边界追溯**：链从时间零点出发、首尾相接、累计绝对时刻收敛；最早边界反向路径还原
  （观测步 + 约束步均正确还原）；精确观测事件的单步证明；无界/无观测返回空；
  停用条目后按有效边重算；
- **分层排程**：单层退化 D=5、内置高/低分层（D=5 / D=0）、耦合整体搜索优于独立夹窗（D=8≠5）、
  字典序优先、三层独立求解、多观测夹逼下排程满足全部观测、D=0、确定性、未连通事件期望被忽略、
  输出满足全部启用约束与观测且各层偏差 ≤ 本层 D、无观测/矛盾返回空；
- **存档迁移**：旧版单锚点存档迁移为一条精确观测并可直接参与分析；锚点事件已删除时不迁移；
  已含观测的存档保留；非法观测剔除；
- 纪元分钟数与本地 ISO 的时区往返一致性。

## 使用指南

1. **添加事件**：在「事件」面板录入关键时点（如：告警触发、服务恢复）；
2. **录入绝对时间观测**：在「绝对时间观测」面板选择事件并填写
   `最早时刻 ~ 最晚时刻`（两端相同即精确时刻）。可对同一事件或不同事件录入任意多条观测；
3. **录入相对约束**：在「时序约束」面板选择 `事件 A —（早于/晚于）— 事件 B`，
   填写分钟区间 `x ~ y`（要求 `0 ≤ x ≤ y`；`x = y` 表示精确间隔）；
4. **查看实时结论**：
   - 顶部绿色横幅：观测与约束可满足，时间窗表给出每个事件的绝对时间窗；
   - 红色横幅：存在矛盾，红色矛盾链同时标出涉及的观测与相对约束，可逐步复核；
     其下方「最小修复建议」给出停用条目最少的方案；
   - 黄色「无法定时」：该事件未被任何观测（经约束）连通，请补充观测或连接二者的约束；
5. **追溯边界依据**：在时间窗表中点击任一事件的**最早时间**或**最晚时间**，
   表下方展开该边界的推导链——从绝对时间零点出发逐步列出用到的观测与原始约束（含录入序号）、
   采用的上界/下界侧不等式与累计绝对时刻，差分图、约束列表与观测列表同步紫色高亮；
   再次点击同一单元格或点击「关闭」收起。单边无界 / 无法定时的单元格不可点击，悬停可查看原因。
   编辑数据或进入/退出修复预览会自动清除当前追溯；
6. **核对矛盾**：可逐条**取消勾选**可疑证词或观测，观察矛盾链是否消失，快速定位冲突来源；
7. **分层最小偏差排程**：系统可满足且至少有一条观测时，底部「分层最小偏差排程」面板可为任意
   事件填写**期望绝对时刻**（留空则不参与），并在其右侧选择**高 / 中 / 低优先级**（默认「中」）。
   系统按 **高 → 中 → 低 字典序**实时求解：先求高层最小容差 `D_高` 并固定，再依次求中、低层，
   最终给出一份同时满足全部约束、观测与各层容差的确定性可行排程。面板**按层**展示每层的最优
   `D`、参与事件数、本层最大偏差与**达到 ±D 的事件**；结果表逐事件列出**层级**、实际绝对时刻、
   期望时刻与期望偏差；未被观测连通的事件在结果中明确标为「未定时」，其上填写的期望与层级
   不参与搜索并会注明未生效。编辑约束、观测、期望或层级后排程实时重算；
   约束矛盾时面板不展示任何旧结果；
8. **采纳修复建议**：
   - 点击方案卡片上的**一键预览**：相关约束/观测被临时停用（置灰并标记“预览停用”），
     图与时间窗立即按修复后的状态展示；预览**只存在于内存，不写入 localStorage**，
     可随时「退出预览」返回原数据，任何编辑操作也会自动退出预览；
   - 点击**确认应用**：方案中的约束/观测被**批量停用**并持久化；
   - 并列最优方案超过 5 个时只展示按录入顺序最靠前的 5 个（会注明总数）；
     搜索累计达到 2000 个状态仍未结束时，面板会提示**结果可能不完备**。

### 状态图例（时间窗表）

| 状态 | 含义 |
| --- | --- |
| **可定时** | 最早与最晚绝对时刻都能由观测与约束推出 |
| **仅单边有界** | 只能推出最早或最晚一侧（另一侧无界） |
| **无法定时** | 未被任何观测（经约束）连通，属于另一连通分量 |

事件行的「有观测」徽章表示该事件自身录有至少一条有效观测。

## 算法说明

### 统一差分图：相对约束 + 绝对观测

每条相对约束 `A 比 B 早 x~y 分钟`（即 `x ≤ t_B − t_A ≤ y`）转换为两条
**差分不等式**，在图中对应两条带权有向边（边 `u → v` 权 `w` 表示 `t_v − t_u ≤ w`）：

- 上界：`t_B − t_A ≤ y` ⇒ `A → B, 权 y`
- 下界：`t_A − t_B ≤ −x` ⇒ `B → A, 权 −x`

`A 比 B 晚 x~y` 时方向互换。

每条绝对观测 `lo ≤ t_i ≤ hi`（`lo`、`hi` 为距 Unix 纪元的分钟数）接到一个统一的虚拟节点
**Z（绝对时间零点，t_Z = 0）**：

- 上界：`t_i − t_Z ≤ hi` ⇒ `Z → i, 权 hi`
- 下界：`t_Z − t_i ≤ −lo` ⇒ `i → Z, 权 −lo`

精确时刻（`lo = hi`，零宽区间）退化为等权双向夹逼。多条观测挂在**同一个 Z** 上，
因此观测之间、观测与相对约束之间的冲突天然表现为同一张图里的负环：
只有连通到 Z 的分量能得到绝对时间窗，未连通分量（正/反向从 Z 都不可达）即「无法定时」。
图中边的来源（约束 / 观测）全程保留，矛盾链与追溯链可准确映射回原始条目。

- **可满足性**：差分系统可满足 ⇔ 图中不存在负权环。使用带「超级源点」（全部节点初始
  距离为 0）的 Bellman-Ford 在第 n 轮检测松弛，时间复杂度 O(V·E)，对复盘场景规模足够；
- **矛盾链提取**：从第 n 轮仍被松弛的边沿前驱指针回溯，先走入环内再裁掉环外尾巴，
  得到一条权重之和严格小于 0 的环；链上任意边来源为观测时标记 `involvesObservation`；
- **时间窗**：以 Z 为源跑最短路得到各事件最晚绝对时刻；在反向图上跑最短路得到最早绝对时刻。
  正/反向均不可达即为「无法定时」。
- **边界依据追溯**：可满足时，最短路的前驱边即从 Z 出发的紧约束链。
  最晚边界直接沿正向图前驱边回溯；最早边界在反向图上取前驱边后，
  逐步还原为原始边（行走方向与原始边相反，权重与上/下界侧不变），
  累计绝对时刻为路径权重前缀和（最早边界取负）。
- **最小修复建议**：在「停用哪些约束/观测可使系统恢复可满足」中求**停用数最少**的方案
  （最小击中集）。修复候选同时包含启用的约束与观测。采用以负环为分支依据的逐层 BFS
  （branch and bound）：
  1. 对当前停用集合跑一次 Bellman-Ford；
  2. 若已无负环，当前集合即为可行方案；
  3. 否则任取一条负环 C——任何可行方案都必须再停用 C 上的至少一个条目，
     故只需对 C 上的不同条目逐一分支（观测、约束同等对待），完备且不会枚举无关条目；
  4. 按停用数 0,1,2,… 逐层展开，**第一次出现可行方案的层即给出最少停用数**，
     同层全部状态都会被考察，以收集并列最优方案；候选项按录入顺序（先约束后观测）展开，
     同层方案按停用条目的录入顺序字典序稳定排序，最多展示 5 个。

  搜索用全局 visited 集合（停用集合的规范化下标元组）去重；累计访问状态数达到
  **2000** 上限即停止：若已找到方案，最少停用数仍已被证明（但并列方案列表可能不全）；
  若尚未找到方案，则明确标记结果可能不完备。每个候选方案复用 `analyze` 计算修复后时间窗。
- **分层最小偏差排程**：设期望事件 `i` 的期望绝对时刻（纪元分钟数）为 `d_i`，其优先级层级
  为 `L(i)`（高/中/低，缺省为中）。按 **高 → 中 → 低** 的字典序逐层优化，对每一层：
  1. **上界**：累计差分系统（原始启用边 + 所有更高层已固定的钉住约束）的任一可行势
     `t*`（超级源点 Bellman-Ford）给出可行上界 `D_ub = max_{i 属于本层} |t*_i − d_i|`；
  2. **二分**：在 `[0, D_ub]` 上二分最小的可行非负整数 `D_L`。对候选 `D`，把本层每个期望
     事件「钉」到时间零点上：加边 `Z → i, 权 d_i + D` 与 `i → Z, 权 D − d_i`，即
     `d_i − D ≤ t_i − t_Z ≤ d_i + D`；在该**整体**差分图上做负环检测判定可行性；
  3. **固定容差**：把本层 `±D_L` 的钉住边**永久并入累计边集**，再求下一层——低层优化
     始终受高层钉住约束限制，绝不可能牺牲高层已达成的容差；尚未求到的更低层此时
     不参与钉住（保持自由），符合字典序语义。

  全部层级求完后，取累计钉住图上的一组可行势（t_Z 已固定为 0，势值即绝对时刻）作为
  **唯一输出排程**：它同时满足全部启用约束、全部观测与各层最优容差；边集与边顺序确定时
  Bellman-Ford 结果确定，故输出是确定性的。由于每层 `D_L` 最小
  （`D_L − 1` 在约束更少的系统上已不可行），最终排程中每层必然有事件达到 ±D_L。

  本算法**不使用加权和、也不分层各自排程后拼接**：所有可行性判定与最终输出都产生自
  同一个累计差分图。也不能用「各事件独立夹到现有时间窗」代替整体搜索：事件间存在耦合，
  例如约束 `t_Y = t_X + 5` 时，窗口为 `X∈[0,5]`、`Y∈[5,10]`；若期望 `X=+10`、`Y=0`，
  独立夹窗会把 `X` 夹到 5、`Y` 夹到 5（各偏差 5）而误判 `D=5`，
  但 `t_X=5 ⇒ t_Y=10`（偏差 10）——整体搜索给出的正确答案是 `D=8`。
  字典序的效果：若 `t_Y = t_X`、期望 `X=+10`（高）、`Y=0`（低），同层平级时最小最大偏差
  为 `D=5`（`t_X=t_Y=5`）；分层求解则高层先把 `X` 钉到 10（`D_高=0`），低层 `Y` 被迫取 10
  （`D_低=10`）——高层目标严格优先。未与任何观测连通的事件不参与搜索，在结果中标记为「未定时」。
- **旧存档迁移**：读取时若发现存档没有 `observations` 字段（旧版单锚点结构），
  则在锚点事件仍存在时，用其 `anchorId` + `anchorTime` 生成一条零宽精确观测
  （`earliest = latest = anchorTime`，默认启用），随后删除旧字段；迁移后的存档与新数据
  走完全相同的计算路径。
